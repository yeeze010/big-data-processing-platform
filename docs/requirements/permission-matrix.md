# 权限矩阵

## 1. 权限原则

- 默认最小权限。
- 管理权限、数据权限和操作权限分离。
- 数据范围按项目空间、数据源、资产标签、敏感等级控制。
- P0 操作必须写审计日志。

## 3. 敏感操作

| 操作 | 控制 |
|---|---|
| 删除数据源 | 二次确认，检查关联任务，写审计 |
| 发布工作流 | DAG 校验，版本留痕，写审计 |
| 重跑任务 | 二次确认，记录参数和操作者 |
| 下载敏感文件 | 生成短期链接，写下载审计 |
| 批量授权 | 展示影响范围，写权限变更审计 |
| 导出审计日志 | 审计员权限，写导出审计 |
