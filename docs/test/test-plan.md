# 测试计划

## 1. 测试范围

- 认证权限、数据范围、审计日志。
- 数据源、采集任务、同步任务、清洗转换聚合。
- 工作流编排、调度触发、失败重试、任务日志。
- 数据质量、异常数据、资产目录、血缘分析。
- 文件附件、告警通知、系统监控。
- GitHub Actions、部署脚本、验收资料归档。

## 2. 测试类型

| 类型 | 覆盖内容 | 工具建议 |
|---|---|---|
| 单元测试 | 规则计算、状态机、权限判断、参数校验 | JUnit/Vitest |
| 接口测试 | REST API、分页、错误码、鉴权、审计 | Postman/Newman |
| 前端测试 | 表单、列表、状态、错误、响应式 | Playwright |
| 集成测试 | PostgreSQL、Redis、MinIO、调度执行器 | Testcontainers |
| 性能测试 | 列表查询、任务触发、日志分页、报表接口 | k6/JMeter |
| 安全测试 | 越权、凭据泄露、SQL 注入、文件下载 | OWASP ZAP |
| 验收测试 | 端到端业务流程 | 人工验收 + 截图 |

## 3. P0 用例

| 编号 | 模块 | 用例 | 预期 |
|---|---|---|---|
| TC-001 | 认证 | 管理员登录成功 | 返回 Token 并进入总览 |
| TC-002 | 权限 | 分析师无法编辑数据源 | 接口返回 403 |
| TC-003 | 数据源 | 新建 PostgreSQL 数据源并测试连接 | 状态为已连接 |
| TC-004 | 采集任务 | 创建增量采集任务 | 保存字段映射和增量配置 |
| TC-005 | 同步任务 | 从断点恢复同步 | 从游标继续执行 |
| TC-006 | 清洗转换 | 配置空值处理和类型转换 | 预览结果正确 |
| TC-007 | 工作流 | 发布合法 DAG | 生成新版本 |
| TC-008 | 调度 | 手动触发工作流 | 生成任务实例 |
| TC-009 | 失败重试 | 重跑失败节点 | 只执行失败节点及下游 |
| TC-010 | 质量 | 非空规则检测失败 | 生成质量报告和异常样本 |
| TC-011 | 异常数据 | 派单并关闭异常 | 状态流转完整 |
| TC-012 | 资产目录 | 任务成功后登记产物 | 资产可检索 |
| TC-013 | 血缘 | 查看产物上游来源 | 展示工作流和字段映射 |
| TC-014 | 文件 | 下载质量报告 | 生成短期链接并写审计 |
| TC-015 | 告警 | 任务连续失败 3 次 | 生成高等级告警 |
| TC-016 | 审计 | 导出审计日志 | 记录导出行为 |
