## 4. 本地运行验证

默认启动命令：

```powershell
npm.cmd start
```

默认地址：

```text
http://127.0.0.1:4173
```

如果 `4173` 被旧进程占用，服务会自动尝试后续端口。本轮为了避免旧服务混淆，使用 `4188` 做了当前代码验证：

```text
http://127.0.0.1:4188
```

验证脚本返回：

```json
{"url":"http://127.0.0.1:4188","home":true,"endpoints":17,"forms":3}
```

含义：

- 首页可以返回，并包含《大数据处理平台》、数据流画布、操作中心与状态流转。
- 三个可操作表单存在：数据源接入申请、任务状态流转、统计报表生成。
- 17 个核心 API 均返回 `200` 且使用统一成功响应包。
