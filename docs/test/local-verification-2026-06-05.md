## 4. 本地运行验证

默认启动命令：

```powershell
npm.cmd start
```

固定地址：

```text
前端 http://127.0.0.1:5214
API  http://127.0.0.1:8214
预览 http://127.0.0.1:6214
```

端口由 `.env.ports` 分配，任一端口被占用时启动直接失败，不会自动切换。

固定端口契约验证：

```powershell
npm.cmd run test:ports
```

含义：

- `5214` 前端代理可以访问 `8214` API。
- `6214` 可以提供构建后的预览产物。
- API CORS 仅允许固定前端和预览来源。
- 固定端口被占用时必须失败。
