# 里程碑计划

| 里程碑 | 周期 | 目标 | 交付物 |
|---|---|---|---|
| M0 立项准备 | 第 1 周 | 冻结范围、角色、技术栈、验收口径 | 需求规格、页面清单、架构草案 |
| M1 基础平台 | 第 2-3 周 | 认证、权限、菜单、审计、工程脚手架 | 登录、用户角色、审计基础、CI |
| M2 数据接入 | 第 4-5 周 | 数据源、采集任务、同步任务、文件上传 | 数据源管理、采集同步、MinIO |
| M3 处理编排 | 第 6-8 周 | 清洗转换聚合、工作流 DAG、调度执行 | DAG 画布、调度、任务实例、日志 |
| M4 质量治理 | 第 9-10 周 | 数据质量、异常数据、资产目录、血缘 | 质量报告、问题池、资产目录、血缘 |
| M5 运维审计 | 第 11 周 | 告警、通知、系统监控、权限审计 | 告警中心、监控、审计导出 |
| M6 联调验收 | 第 12 周 | 全链路演示、缺陷关闭、封版发布 | 测试报告、验收材料、v1.0.0 Release |

## 验收封版条件

- P0 功能全部可演示。
- P0 测试用例全部通过。
- GitHub Actions 通过。
- `main` 分支代码完整。
- `v1.0.0` tag 和 Release 已创建。
- 验收材料归档到 `docs/acceptance/`。
