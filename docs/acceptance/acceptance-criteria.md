# 验收标准

## 1. 功能验收

| 验收项 | 标准 |
|---|---|
| 数据源管理 | 支持新增、编辑、查询、连通性测试和状态展示 |
| 采集任务 | 支持来源、目标、字段映射、增量策略和预检查 |
| 同步任务 | 支持全量、增量、断点续传和同步校验 |
| 清洗转换聚合 | 支持字段转换、空值处理、去重、聚合配置 |
| 工作流编排 | 支持 DAG、节点依赖、参数、版本、发布 |
| 任务调度 | 支持定时、手动、补数、暂停、终止、失败重试 |
| 数据质量 | 支持规则配置、检测、报告和异常样本 |
| 异常数据 | 支持问题池、派单、处理、复核、关闭 |
| 数据资产目录 | 支持资产登记、标签、负责人、生命周期 |
| 血缘关系 | 支持表级血缘、字段级血缘、影响分析 |
| 权限审计 | 支持角色权限、数据范围和操作审计 |
| 告警通知 | 支持规则、告警事件、确认、关闭、升级 |
| 文件附件 | 支持上传、下载、版本、授权和下载审计 |

## 2. 性能验收

- 常规列表 2 秒内响应。
- 任务触发接口 1 秒内返回。
- 10 万条任务日志分页稳定查询。
- 总览看板 1 秒内返回核心指标。

## 3. 安全验收

- 未登录不能访问业务接口。
- 越权访问被拦截。
- 敏感凭据不明文返回。
- 敏感文件下载有审计。
- 审计日志普通管理员不可删除。

## 4. 可用性验收

- 核心页面有加载、空状态、错误状态。
- 危险操作有二次确认。
- 表单错误就近提示。
- 页面适配 375、768、1024、1440 宽度。

## 5. 交付物验收

- `docs/requirements/` 需求规格完整。
- `docs/architecture/` 架构、数据模型、图示完整。
- `docs/design/` 前端交互设计完整。
- `docs/api/` 接口规划完整。
- `docs/test/` 测试计划完整。
- `docs/deployment/` 部署方案完整。
- `docs/acceptance/` 验收标准完整。
- GitHub Issue、PR、Actions、Release 规范完整。
